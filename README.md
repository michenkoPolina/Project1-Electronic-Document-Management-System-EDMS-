# Project1-Electronic Document Management System (EDMS)
Совершенствоание процессов документооборота в таможне
## Описание проекта: 
Разработана модель бизнес-процессов документооборота в таможенном управлении

## Используемые инсрументы: 
1. BPMN;
2. UML-диаграммы;
3. Draw.io;
4. Miro;
